## Commands Practiced

- `echo` — prints text to the terminal
- `whoami` — displays the currently logged-in user
- `ls` — lists files and folders in the current location
- `cd` — changes the current directory
- `pwd` — prints the current working directory
- `cat` — displays the contents of a file
- `find` — searches for files across the system
- `grep` — searches for specific words inside files

---

## Operators Learned

- `&` — runs a command in the background so you can
keep working while it executes
- `&&` — combines multiple commands; the second command
only runs if the first one succeeds
- `>` — redirects output into a file, replacing existing
content
- `>>` — appends output to a file without overwriting
what is already there

## What I Learned

Linux is an operating system first released in 1991. It now
powers most servers and cybersecurity tools around the world.
Although Linux also has graphical desktop environments, 
cybersecurity professionals primarily use the terminal because 
it is faster and more efficient for managing systems remotely.

I learned that being comfortable in the Linux terminal is
essential for a SOC Analyst because security investigations
involve navigating systems, reading log files, and searching
for suspicious activity — all done through the command line.

One of the most useful commands I learned was grep.Instead
of reading through thousands of log lines manually, grep
lets you search for exactly what you need in seconds.

The operators were also interesting — they allow you to run
commands in the background, chain commands together, and
redirect output into files, which makes working in the
terminal much more efficient.

---

## Key Takeaways

- The Linux terminal is faster and more powerful than a
graphical interface for security tasks
- grep saves significant time when analyzing log files
during an investigation
- Operators make it easier to automate and chain commands
- Linux skills are listed as a requirement in most
cybersecurity job postings
